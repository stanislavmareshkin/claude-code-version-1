## 2. Технический SEO (вес: 35%)

### Чек-лист по методологии IndexLift

#### 2.1 HTTPS и безопасность
- [ ] Проверить, что все страницы elpcargo.ru работают по HTTPS
- [ ] Убедиться в отсутствии mixed content (HTTP-ресурсы на HTTPS-страницах)
- [ ] Проверить редиректы: http -> https, www -> без www (или наоборот)

#### 2.2 Crawl & Discovery
- [ ] **robots.txt** — создать/проверить файл `https://elpcargo.ru/robots.txt`
  ```
  User-agent: *
  Allow: /
  Disallow: /wp-admin/
  Disallow: /cart/
  Disallow: /checkout/

  User-agent: Yandex
  Allow: /
  Host: elpcargo.ru

  Sitemap: https://elpcargo.ru/sitemap.xml
  ```
- [ ] **XML Sitemap** — создать/обновить `sitemap.xml` со всеми посадочными страницами
- [ ] **Yandex Host директива** — указать основное зеркало в robots.txt

#### 2.3 Канонические URL
- [ ] Canonical тег на каждой странице указывает на саму себя
- [ ] Избегать кириллических URL (как `/международная-доставка-как-ключ-к-гло/`) — использовать транслитерацию
- [ ] Убедиться, что canonical совпадает с финальным URL после редиректов

#### 2.4 Мета-атрибуты
- [ ] Указать `lang="ru"` в теге `<html>`
- [ ] Указать `charset="UTF-8"`
- [ ] Добавить viewport мета-тег для мобильных


### 3.2 Заголовки (H1-H3)
- [ ] Ровно один `<h1>` на каждой странице, совпадающий с основным ключевым запросом
- [ ] Использовать `<h2>` для основных секций, `<h3>` для подсекций
- [ ] Избегать повторения одинаковых заголовков на разных страницах

### 3.3 Контент
- [ ] Минимум 800-1200 слов на коммерческих посадочных страницах
- [ ] Минимум 1500-2500 слов на информационных страницах (`/kak-dostavit/`)
- [ ] Добавить списки (ul/ol) для перечисления услуг, маршрутов, этапов
- [ ] Добавить таблицы для сравнения сроков/стоимости по маршрутам

### 3.4 Изображения
- [ ] Alt-тексты с ключевыми словами на всех изображениях
- [ ] Сжатие изображений (WebP формат)
- [ ] Указание width/height для предотвращения layout shift

### 3.5 Внутренняя перелинковка
- [ ] Каждая страница должна ссылаться на 3-5 других релевантных страниц
- [ ] Использовать анкоры с ключевыми словами (не "подробнее", а "доставка из Англии")

## 6. GEO — Generative Engine Optimization (AI-видимость)

### 6.1 Answer-First Intros
Каждая страница должна начинаться с прямого ответа на ключевой вопрос:

**Пример для главной:**
> ELP Cargo — транспортно-логистическая компания, специализирующаяся на доставке санкционных грузов из Европы, Китая и США в Россию через механизмы параллельного импорта и реэкспорта.

**Пример для `/kak-dostavit/`:**
> Доставить санкционные товары в Россию можно легально через реэкспорт из третьих стран (Турция, Казахстан, Армения) или через параллельный импорт, разрешённый в России с 2022 года.

### 6.2 Question-Led Structure
Организовать контент вокруг вопросов пользователей:
- "Как доставить санкционные товары в Россию?"
- "Сколько стоит доставка из Европы?"
- "Какие сроки доставки грузов?"
- "Какие товары можно ввозить через параллельный импорт?"
- "Нужно ли таможенное оформление?"

### 6.3 Chunkable Content Structure
- [ ] Разбить контент на логические секции с подзаголовками
- [ ] Использовать нумерованные списки для пошаговых процессов
- [ ] Добавить таблицы для структурированных данных (маршруты, сроки, цены)
- [ ] Создать summary/TL;DR блоки в начале длинных статей

### 6.4 Source Citation Support
- [ ] Ссылаться на официальные источники (законы, постановления правительства)
- [ ] Указывать актуальные нормативные акты по параллельному импорту
- [ ] Добавить ссылки на ФТС, Минпромторг и др. ведомства

### 6.5 Entity & Author Attribution
- [ ] Указать авторов экспертного контента
- [ ] Добавить даты публикации и обновления на каждую статью
- [ ] Создать страницы авторов с квалификацией в логистике

### 6.6 Freshness Signals
- [ ] Добавить `datePublished` и `dateModified` в schema markup
- [ ] Обновлять статью "Как доставить" минимум раз в квартал
- [ ] Указывать актуальный год в title ("...в 2026 году")
