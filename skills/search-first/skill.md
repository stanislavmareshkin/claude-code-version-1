# Search-First Development

## When to Activate

- Before implementing any new feature
- When encountering an error or bug
- When choosing between approaches
- Before adding a new dependency

## Process

1. **Search the codebase first** — Use Grep/Glob to find existing patterns
2. **Check for existing solutions** — Don't reinvent the wheel
3. **Read documentation** — Check official docs before guessing
4. **Look at similar implementations** — Find related code in the project
5. **Then implement** — Only after understanding the context

## Rules

- Always search before creating new files
- Check if a utility/helper already exists
- Follow existing patterns in the codebase
- Read the file before editing it
- Understand the context before making changes

## Anti-patterns

- Creating duplicate utilities
- Ignoring existing patterns
- Implementing without reading related code
- Adding dependencies for things already available
